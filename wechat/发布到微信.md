# 微信发布步骤 · 1.5.3

本目录可直接导入微信开发者工具。首页二维口腔，点击「全屏沉浸」进入无口腔三维；普通页面采用手机网页的可滚动卡片布局，底部有四个导航入口。当前交付没有替你上传、提交审核或发布。

## 1. 先预览新版

1. 先保存旧工程中你自己的未保存修改，再到开发者工具首页导入新版目录：`成品/微信小程序-1.5.3/微信小程序源码`。目录内应能看到 `project.config.json`。旧版本源码目录保留。
2. 类型选「小程序」，后端服务选「不使用云服务」。无需安装依赖或构建 npm，点击「编译」。
3. 首页检查大标题、健康提示和二维口腔，向下滚动检查换包及独立吸烟卡片；进入沉浸检查三维旋转、拖烟、缩放；退出后咀嚼次数、形态和香烟状态应保留。
4. 点击工具栏「预览」，用有项目权限的微信扫码，在实际手机上检查画面、音效、吐渣、燃尽后重新点烟，以及切后台和重新打开。请保留本机存储，清除存储会影响访客记录。

本版已通过 27 项单元/客户端测试、官方 WXML/WXSS 编译和 320/360/390 像素浏览器适配检查。浏览器检查不是微信真机验收，本次尚未完成实际微信运行时及手机验收。

## 2. 确认正式小程序账号

在 [微信公众平台](https://mp.weixin.qq.com/) 登录自己的小程序，确认主体、AppID 和管理员/开发者权限。

此前开发者工具把 `wxa4973df8756ffee9` 显示为「接口测试号」；如果仍是测试号，只能开发测试，正式发布需注册正式小程序并将 `project.config.json` 的 `appid` 换成正式 AppID。AppSecret 不要写进源码。更换 AppID 会使用另一套本机存储，原测试号访客记录不会自动搬迁；云端仍使用原网页账号 ID。

补齐名称、头像、简介、真实服务类目、公开联系渠道、用户隐私保护指引，并按公众平台提示完成小程序备案（设置 → 小程序备案；首次备案也可能从首页入口进入）。备案号按平台要求展示。个人主体可选类目以后台实际提供为准。

本项目包含模拟咀嚼/吸烟互动和自报戒除记录，应如实描述功能；健康提示不保证审核通过。若平台判定应按「小游戏」接入，当前小程序工程不能仅改 `compileType` 就直接发布，需按小游戏规则另行适配。

## 3. 选择是否接入云账号

**先体验本机版：**保持 `miniprogram/config.js` 的 `apiBase: ''`，无需为了本地模拟配置服务器域名。统计、成就、打卡和省钱设置保存在手机本机，云登录不可用；这不免除小程序本身的备案、类目和审核要求。请填写 `contact` 为自己的公开联系渠道。

**接入原网站账号：**后台至少为 1.5.0，使用原 MySQL 数据库，无须重建账号或表。先为接口配置已备案域名、有效 HTTPS 和反向代理，再到公众平台「开发管理 → 开发设置 → 服务器域名」加入 `request` 合法域名。`apiBase` 填 `https://你的域名`，不要带 `/api`。

现有 `http://101.201.68.203:8081` 不能直接用于正式小程序云同步；微信网络要求 HTTPS 合法域名，不能用公网 IP 或 localhost。开发工具的「不校验合法域名」不是上线方案。小程序前端代码上传到微信；云账号 API 才运行在自己的 Windows Server。接入详见 [README](README.md)。

## 4. 上传、审核、发布

1. 真机预览通过后，在微信开发者工具右上角点 **上传**。版本号填 `1.5.3`，备注可填「手机网页布局，独立放下练习，累计与今日统计」。按提示由管理员确认。
2. 到公众平台 **管理 → 版本管理**（有的界面在开发管理中），在「开发版本」找到刚上传的版本。可先设为体验版，并为测试人员添加体验成员权限。
3. 点击 **提交审核**，如实填写功能、服务类目、隐私及备案等信息；如果开放云登录，按审核页面要求提供可用测试账号。不要提供数据库密码。
4. 审核通过后，在「审核版本」点击 **发布**。普通首次上线可选择全量发布。只有完成此步，正式小程序码才会进入已发布版本。
5. 发布后用非开发者微信扫码检查正式版。如后续升级，仍走上传 → 审核 → 发布，微信负责小程序版本分发；这与 EXE/APK 的 OTA 是不同流程。
