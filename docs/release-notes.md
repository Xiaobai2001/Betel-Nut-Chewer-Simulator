# 嚼槟榔模拟器 1.2.0 · 账号网页版

新增访客自行注册与登录。登录后的咀嚼次数、开始颗数、完成颗数和吐出颗数保存到 MySQL，提供今日、累计及近 7 天统计。支持断网暂存、恢复补传、重复请求去重与账号隔离。

全屏模式把咀嚼、吸吐烟、换包操作移到画面下方，保持明亮背景、无嘴巴的第一人称画面；电脑和手机横竖屏均使用底部操作区。

## 本次下载

- `ChewSimulator-1.2.0-WebAccounts.zip`：Windows Server 账号版部署包，需 Node.js 24 + MySQL 8.0，默认端口 8081。完整解压后按 README 运行 Install-Accounts.ps1，输入服务器数据库管理密码。
- 同名 `.sha256`：部署 ZIP 的 SHA-256 校验值。
- `ChewSimulator-1.2.0-Source.zip`：源码备份，不含数据库密码、签名、依赖缓存或客户端二进制文件。

安装脚本创建专用数据库账号、建表和 Windows 开机任务。数据库密码仅保存在服务器私有配置中。旧 IIS 8080 网站可继续保留。

## 验证与范围

已在独立 MySQL 8.0.33 测试实例验证注册、密码哈希、登录/退出、数据持久化、并发去重、错误回滚、账号隔离和北京时间分日；浏览器验证断网后刷新再补传、多标签页、统计页面以及原有模拟和全屏交互。部署脚本已做 PowerShell 语法检查，数据库初始化及密码重置已实际运行测试。

Windows Server 的任务计划、防火墙和公网访问由部署者验收。HTTP 仅建议使用独立测试密码；正式提供账号登录建议启用 HTTPS。

**本次未重新发布 EXE / APK。已有 1.1.1 客户端仍为离线版，没有账号、MySQL 同步或 OTA。** 客户端安装包请查看 v1.1.1 发布。

所有动作均为虚拟视觉模拟。槟榔致癌，吸烟有害健康，建议戒除。
