# 嚼槟榔模拟器 1.1.1

全屏采用明亮奶油白界面，移除全屏口腔与牙齿，只保留第一人称三维画面。支持旋转、缩放、咀嚼形变、吐渣落地、换包、点烟与吸吐烟，并包含戒槟榔、戒烟提醒。

- Windows：下载 `ChewSimulator-1.1.1-Windows.exe`，双击运行。
- Android：下载 `ChewSimulator-1.1.1-Android.apk`，传入手机确认安装。沿用原签名，可覆盖旧版。
- 离线网页：解压 `ChewSimulator-1.1.1-Web.zip`，打开 `web/index.html`。
- 先上线网页版：解压 `ChewSimulator-1.1.1-WebServer.zip`，按 README 部署 IIS；此小包不含 EXE / APK，独立校验值在同名 `.sha256` 文件。
- Windows Server：解压 `ChewSimulator-1.1.1-WindowsServer.zip`，按 README 部署 IIS 静态网站和下载页。

网页与 Windows 程序已运行验证。APK 已通过签名检查，尚未实体手机验收。服务器脚本在开发电脑做语法与部署文件检查，服务器由用户自行部署。当前 EXE / APK 尚未具备 OTA，请手动下载更新。

所有动作均为虚拟视觉模拟。槟榔致癌，吸烟有害健康，建议戒除。
