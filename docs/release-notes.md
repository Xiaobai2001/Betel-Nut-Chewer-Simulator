# 嚼槟榔模拟器 1.5.0 · 微信小程序原生源码

新增可直接导入微信开发者工具的 WXML / WXSS / JavaScript 工程。支持咀嚼形变、吐渣/吐出、三档换包、吸吐烟、旋转和拖动、明亮沉浸布局、音效及拆包动画；包含包装统计、戒除成就、现实打卡和用户自填的省钱基准。

- 下载 `ChewSimulator-1.5.0-WeChat.zip`，解压后导入内层 `微信小程序源码`，无需构建 npm。原生 Canvas 2D 重绘立体形态，未直接移植网页 Three.js。
- 默认无服务器配置，访客记录仅保存在本机。源码预填用户提供的开发 AppID；开发者工具当前显示为接口测试号，正式发布需换成正式小程序 AppID。
- 后台新增 `/api/native/*` Bearer 认证，使用原 MySQL 账号 ID、统计、打卡和花费设置；网站继续使用 HttpOnly Cookie 和原来源校验。没有数据库表变更。
- 云账号使用原用户名/密码，未实现微信一键登录。事件断网排队，按账号隔离，服务端去重；会话过期后可重登原账号继续补传，访客记录不合并。

连接云账号前，使用 `ChewSimulator-1.5.0-WebAccounts.zip` 升级服务器，并配置有效 HTTPS 域名及微信 request 合法域名。公网 IP / HTTP 不可作为正式小程序接口。已有账号版请解压到新的更新目录，运行 `Update-Accounts.ps1`，按提示备份后更新，保留原 `.private` 和数据库。

验证：23 项单元/客户端测试、独立 MySQL 8.0.33 原生/网页接口及浏览器回归、微信官方 WXML/WXSS 编译器、四页编译模板渲染检查通过；Canvas 与手机布局使用 Chromium 适配层验证。尚未完成微信真机验收、公众平台上传、审核或发布。正式发布仍需核对主体、备案、类目、隐私申报及平台资质要求。

包含小程序源码 ZIP、账号后台部署 ZIP、完整源码 ZIP 和 SHA-256。服务器由用户自行部署；现有 EXE/APK 仍为 1.1.1 离线版，本次未重建或实现 OTA。
