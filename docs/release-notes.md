# 嚼槟榔模拟器 1.5.3 · 小程序采用手机网页布局

普通页面按手机版网页重排：顶部账号与音效、大标题、健康提示、二维咀嚼卡片、本次体验、三档包装、独立吸烟卡片和呼吸入口依次向下，支持自然滚动。画布、字体、按钮和留白恢复网页的手机尺寸。

- 底部四个入口：模拟体验、放下练习、记录与成就、使用说明。图标由网页原 SVG 转换成本地 PNG，账号从顶部进入。
- 放下练习改为独立页面，包含呼吸圆环、开始/结束按钮与支持建议。完整 60 秒才计一次，提前结束、离开页面或切后台不计完成。
- 记录页使用四张统计卡片，支持累计/今日切换；用量、包装袋与烟盒折合同步切换，现实打卡、成就和省钱仍按既有口径展示。
- 首页二维、全屏三维；全屏保留底部操作，退出恢复原滚动位置和模拟状态。账号 ID、数据存储键、同步协议及数据库结构未改变。
- 新版独立目录：`成品/微信小程序-1.5.3/微信小程序源码`。旧工程保留；WeChat.zip 解压后可直接导入，无需构建 npm。

27 项单元/客户端测试、五页官方 WXML/WXSS 编译和 320/360/390 像素浏览器适配检查通过。检查包括纵向卡片顺序、滚动后烟雾操作可达、按钮无横向裁切、二维形变、三维拖动、全屏退出恢复位置、呼吸计数和累计/今日统计。已目视对照本地网页版的手机渲染。浏览器适配不是微信真机验收；本次未上传微信或提交审核。

1.5.0 及以上账号后台兼容，无须为这次布局更新升级服务器。默认仍是本机访客版，云账号需 HTTPS 合法域名；正式微信发布需正式 AppID 和平台要求的备案、类目等。EXE/APK 仍为 1.1.1 离线版，未重建或实现 OTA。
