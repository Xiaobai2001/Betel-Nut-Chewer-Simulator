# 嚼槟榔模拟器 1.5.1 · 小程序画面与网页对齐

1.5.0 小程序使用了独立简化绘图，且微信默认按钮宽度造成访客文字竖排、控件撑宽和横向裁切。本版复用网页场景并修复原生布局。

- 通过微信 Three.js 适配层复用网页三维模型、程序纹理、形变、烟雾和吐渣；正常模式与全屏沉浸均可旋转槟榔、独立拖动香烟。WebGL 不可用时使用网页原有的槟榔绘图，并标注兼容画面。
- 还原网页标题、健康提示、咀嚼实验室与三档包装袋外观。修复微信 style-v2 默认按钮固定宽度，防止标签竖排与操作被横向裁切。
- 账号、统计、成就、打卡和省钱逻辑不变。原 1.5.0 后台仍兼容，不需要重建数据库；本版没有新增表。
- 下载 WeChat.zip 解压后导入「微信小程序源码」，无需 npm 构建。本机修正版另存为「成品/微信小程序修正版」，原导入目录保留。

23 项单元/客户端检查、官方 WXML/WXSS 编译及四页模板执行通过。360/390 像素浏览器适配检查加入微信默认按钮宽度，验证按钮边界、访客标签与沉浸操作；实际运行微信适配版 WebGL 场景，检查旋转、拖动、形变和粒子效果。尚未完成新版在微信运行时与真机上的验收。公众平台未上传或提交审核。

AppID、HTTPS 合法域名和备案/类目要求与 1.5.0 相同。当前提供的 AppID 在开发者工具显示为接口测试号。EXE/APK 仍为 1.1.1 离线版，未重建或实现 OTA。
