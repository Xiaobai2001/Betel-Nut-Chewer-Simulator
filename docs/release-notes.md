# 嚼槟榔模拟器 1.4.0 · 省钱记录与沉浸互动

- 现实戒除省钱估算：各账号填写原来用量和价格，未设置不显示金额；按现实打卡计算，更正打卡或修改设置后重算，支持跨设备读取。
- 沉浸场景按参考比例放大，槟榔与香烟分开；拖槟榔旋转、拖香烟移动，R 同时复位。亮白背景，无口腔和牙齿。
- 独立合成咀嚼、吸气、吐气和拆袋音效；M 开关音效，默认关闭。换包显示撕袋动画，遵循减少动态效果偏好。
- 新增 Update-Accounts.ps1：识别原安装目录，先备份数据库、配置和应用，再原位更新，保留账号 ID、密码、历史统计、成就和打卡。保留旧版事件补传兼容，并避免超大账号 ID 的精度碰撞。
- 修复首次安装时空网址导致失败的提示和校验。

下载 `ChewSimulator-1.4.0-WebAccounts.zip`，解压到服务器新的 `C:\ChewUpdate` 目录，以管理员 PowerShell 运行 `Update-Accounts.ps1`。按提示输入 MySQL 管理凭据。详情见 ZIP 内 README.md。不要先覆盖旧目录或删除 `.private`。

包含 WebAccounts.zip、SHA-256 校验文件、Source.zip。现有 EXE/APK 仍为 1.1.1 离线版，本次没有重新构建或实现客户端 OTA。云服务器由用户自行更新。
