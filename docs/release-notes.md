# 嚼槟榔模拟器 1.3.0 · 记录与戒除成就

新增“记录与成就”页面：今日/累计槟榔与香烟用量、可视包装袋与烟盒、近 7 天记录、主动放下与呼吸练习成就，以及自愿填写的现实戒除打卡。所有数据按账号同步。

50 / 100 / 200 档每包分别调整为 **10 / 15 / 20 颗**，香烟每盒 **20 根**。包装区按嚼过颗数、点燃根数折算，反复换包不会虚增消耗。点燃、吸过、抽完、提前熄灭和吸烟口数分别保存。

现实打卡与模拟用量分开；可以更正近 7 天，显示连续和历史最佳天数。共 9 项觉察、休息与戒除成就；用量达到提醒线只提示休息，没有高消耗奖励。没有打卡不会被推断成现实戒除。

## 下载与升级

- `ChewSimulator-1.3.0-WebAccounts.zip`：Windows Server + Node.js 24 + MySQL 8.0 部署包。
- 同名 `.sha256`：部署 ZIP 校验值。
- `ChewSimulator-1.3.0-Source.zip`：源码备份，排除私有配置、密钥及构建缓存。

**已经安装 1.2.0 的用户，也必须运行新版 Install-Accounts.ps1，并输入 MySQL 管理凭据创建新增表。** 保留原 `.private/server.json` 和数据库。升级只新增两张表；旧账号和统计保留。旧版待同步事件继续按每包 8 颗重放，旧数据单独标注，不伪造烟盒与打卡历史。安装、备份与更新步骤见包内 README。

## 验证

12 项模型与成就规则测试通过；独立 MySQL 8.0.33 验证了旧库升级、三档归属、烟盒计数、自然燃尽与提前熄灭、现实打卡更正、账号隔离、并发去重和旧队列兼容。浏览器验证包装展示、完整呼吸练习、断网刷新补传、切换账号、全屏和手机布局。

服务器的开机任务、防火墙与公网访问需在你的 Windows Server 上验收。当前 HTTP 个人测试请使用独立密码。
