# 嚼槟榔模拟器 1.5.2 · 二维首页与三维沉浸

小程序打开即显示二维模拟区，复用网页版的口腔、槟榔形变、收集盘和香烟绘图。仅进入「全屏沉浸」时加载无口腔三维场景，支持旋转、缩放与独立拖烟；退出恢复二维，当前咀嚼、香烟状态和统计保持不变。

- 去除模拟区前的大标题和说明，按手机可用高度排版。画布、咀嚼、吸吐烟和换包按钮位于同一竖屏，小屏自动紧凑；保留健康提醒和呼吸入口。
- 进入后台销毁画布，取消过期的模式切换和异步初始化，避免返回页面后场景错位或继续绘制。
- 新增逐步微信发布指南。新版源码另存为 `成品/微信小程序-1.5.2/微信小程序源码`，保留旧工程；下载 WeChat.zip 后可直接导入，无需 npm 构建。
- 账号、统计、成就、打卡和省钱逻辑不变。原 1.5.0 及以上后台兼容，不需要重建数据库；已有服务器无须为这次小程序界面更新而升级。

24 项单元/客户端检查、官方 WXML/WXSS 编译及四页模板执行通过。320/360/390 像素浏览器适配检查验证二维口腔绘制、三维渲染、旋转、拖烟、形变、吐渣，以及所有主操作在可用竖屏高度内无需滚动。尚未完成新版在微信运行时与真机上的验收，公众平台未上传或提交审核。

当前配置 AppID 此前在开发者工具显示为接口测试号；正式发布需正式 AppID、小程序备案及合适类目。默认本机访客；连接原云账号需 HTTPS 合法域名。EXE/APK 仍为 1.1.1 离线版，未重建或实现 OTA。
