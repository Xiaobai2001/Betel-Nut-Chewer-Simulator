# 嚼槟榔模拟器

一个以奶油白和橄榄绿为主色的本地互动模拟器。所有包装、动作和烟雾均为虚拟示意，没有真实商品或支付。当前 1.4.0 账号网页版支持用量、包装展示、戒除成就与现实打卡；现有 EXE / APK 仍是 1.1.1 离线版。

## 直接使用

本机成品统一放在 `成品/本机运行` 文件夹中；服务器和 GitHub 使用相邻的专用发布目录：

- **Windows**：双击 `嚼槟榔模拟器-Windows.exe`，无需安装 Node.js，也无需联网。适用 Windows 10/11 的 64 位电脑。首次启动需要解压运行文件，可能稍等几秒。
- **安卓**：将 `嚼槟榔模拟器-Android.apk` 传到手机，使用手机的安装程序安装，然后打开“嚼槟榔模拟器”。APK 已用本项目的本地证书签名，不需要登录，也没有网络、相机、麦克风或定位权限。系统最低 Android 6.0，建议 Android 8.0 及以上，并使用较新的 Android System WebView。尚未在实体安卓手机上验收。
- **网页**：双击 `网页版/index.html`，或使用项目根目录的 `打开网页版.html`。建议使用新版 Chrome 或 Edge。移动或分享网页版时，要保留整个 `网页版` 文件夹；也可以发送已打包的网页版 ZIP。

核心模拟可离线使用。账号统计、跨设备同步与现实打卡需要打开部署后的账号服务器网址。EXE 没有商业代码签名，APK 使用项目自己的签名证书，均不是应用商店发布版本。

## 操作

1. **嚼一口**：点击按钮，或在模拟页面的空白处按空格。咀嚼使槟榔逐渐压扁、颜色加深、纤维散开。15 口后完全纤维化，自动咀嚼会停止。
2. **自动咀嚼**：打开开关后每隔约 0.76 秒嚼一口。切换页面、窗口失焦或进入后台会停止。
3. **吐渣**：把积累的碎纤维吐到虚拟收集盘，保留当前槟榔的咀嚼程度。
4. **吐出槟榔**：吐出整颗；按钮随后变成“取一颗”。空包时会显示“换包并取一颗”。
5. **换包**：50 / 100 / 200 对应三种虚构包装。当前网页每包分别为 10 / 15 / 20 颗，切换后保留嘴里已有的槟榔。“重新换包”补充当前包装，并显示撕开封条、袋口打开的动画；系统开启减少动态效果时使用静态提示。无购买或付费行为，档位不代表安全性。
6. **点烟模拟**：可以独立点燃，不再要求口中有槟榔。抽完或手动熄灭后可“再点一根”；最后一口尚未吐出时，再点一根会重置旧烟状态。依次点击“吸一口”“吐烟”观察变化，香烟随时间和吸入逐渐变短。可随时“熄灭”。当前网页每盒 20 根，空盒后再次点燃会自动取新盒。
7. **音效**：右上角开关，默认关闭。程序用音频合成生成咀嚼、吸气、吐气和拆袋音效；沉浸模式中也有开关，M 快捷切换。
8. **放下练习**：开始一分钟自然呼吸练习时，会清空口中的虚拟槟榔并熄灭香烟。4 秒轻轻吸气、6 秒缓缓呼气，共 6 轮，可随时结束。

访客计数只在本次会话保留。账号网页版的统计、包装足迹和打卡保存到服务器，断网模拟操作在本机暂存；当前模拟在刷新后重置。左侧/手机底部“记录与成就”可查看详情，口径见 [记录与戒除成就](progress.md)。没有排行榜或购买入口。已有 1.1.1 EXE / APK 的包装仍为 8 颗，尚未接入上述账号功能。

## 明亮沉浸模式

点击“全屏沉浸”或按 F，进入放大的三维场景。采用明亮奶油白界面、浅色场景和柔和投影，只保留无嘴巴、无牙齿的第一人称画面，香烟位于右侧。鼠标或手指拖动槟榔可以旋转，拖动香烟可以独立移动，滚轮或滑块调整大小。吐渣从视角前方向外喷出，受重力下落并留在地面，吐整颗带弹跳效果。“清理地面”清空这些虚拟残渣。

沉浸模式和普通模式共用当前槟榔、烟、包装及计数。退出不丢失进度。可以在沉浸模式中直接换包、点烟、吸烟、吐烟，或选择“放下，呼吸一分钟”。

| 按键 | 动作 |
| --- | --- |
| F / Esc | 进入或退出沉浸；Esc 只退出 |
| Space | 嚼一口 / 取一颗 |
| Q / G | 吐渣 / 吐出整颗 |
| L / I / O / X | 点一根或再点一根 / 吸 / 吐烟 / 熄灭 |
| A | 开关自动咀嚼 |
| 1 / 2 / 3 | 50 / 100 / 200 换包 |
| R | 沉浸模式中旋转、缩放与香烟位置复位 |
| M | 音效开关（网页 1.4.0） |
| 方向键 | 沉浸模式中旋转微调 |

快捷键在模拟页面有效，输入框或缩放滑块获得焦点时保留原生输入。手机也提供全部操作按钮。网页版和 EXE 使用系统全屏；系统全屏不可用时铺满应用页面。安卓版增加了隐藏应用系统栏的沉浸模式，按返回先退出沉浸；尚未在实体手机验证。三维模式需要支持 WebGL 2 的较新浏览器 / Android System WebView，不支持时自动切换为二维兼容画面。

历史 1.1.1 客户端修复：吐出槟榔后不能重新点烟；最后一口烟、燃尽和手动熄灭后的重新点燃。Android 版本号已提升为 3，仍用原有签名，可以覆盖更新旧版。旧版成品分别保存在 `.build/backups/v1.0.0/` 和 `.build/backups/v1.1.0/`。1.1.1 移除全屏口腔模型、牙齿和 V 切换视角快捷键，并将全屏三维背景、地面与操作面板全部改为亮色。

## 健康提示

槟榔具有明确致癌风险，不含烟草的槟榔也不安全。吸烟危害健康，与槟榔并用会增加风险。建议戒槟榔、戒烟。本程序只是视觉模拟和放松提醒，不能替代专业医疗或戒断治疗。口腔溃疡两周不愈、张口受限等应及时到口腔科检查。

参考：IARC Monographs Volume 85；WHO Tobacco fact sheet。

## 源码与重新构建

- `app/`：网页界面、动画和交互；三维场景使用本地打包的 Three.js，无 CDN 依赖。
- `src/immersive-scene.js`：三维模型、旋转、形变、烟雾与吐渣落地效果的源码。
- `desktop/`：Electron 桌面外壳，关闭 Node 集成，启用隔离与沙箱。
- `android/`：原生 Android WebView 外壳，无第三方运行时或网络权限。
- `tests/`：状态边界、浏览器交互、桌面程序验证。
- `tools/`：本地服务器、图标生成、Android 构建、成品整理脚本。
- `deploy/windows-server/`：服务器使用的 IIS 配置与部署脚本。
- `.private/android-signing/`：仅本机保存的签名，不上传 GitHub 或服务器。

在本机项目目录的 PowerShell 中运行：

```powershell
npm.cmd install
npm.cmd test
npm.cmd run serve
```

服务器仅监听 `127.0.0.1:4173`。使用 Ctrl+C 停止。

构建环境：Node.js 24、Python 3.11、Pillow、JDK 26、Android API 35 / Build Tools 35、Electron 38.8.6。

在本机项目目录的 PowerShell 中重新构建：

```powershell
$env:ELECTRON_MIRROR='https://npmmirror.com/mirrors/electron/'
$env:ELECTRON_BUILDER_BINARIES_MIRROR='https://npmmirror.com/mirrors/electron-builder-binaries/'
$env:PYTHONIOENCODING='utf-8'
python tools/make_icon.py
node tools/build_scene.cjs
npm.cmd run build:win -- --config.electronDist=node_modules/electron/dist
python tools/build_android.py
python tools/package_delivery.py
```

Android 脚本自动下载 Google 官方 SDK 构建工具并校验仓库公布的 SHA-1；不依赖 Android Studio。`.private/android-signing/` 中的密钥及密码用于以后覆盖升级，请备份并保留，不要随成品公开分享。工具缓存位于 `.build/`，编译产物位于 `.build/releases/`，都不是服务器运行网页所必需的文件。

浏览器测试需本地服务正在运行；桌面测试需已经完成 Windows 打包：

```powershell
node tests/browser.cjs
node tests/immersive.cjs
node tests/desktop.cjs
```

截图在 `.build/test-results/`，验证记录在 `docs/validation.md`。安卓签名与 APK 结构已验证；实体手机的安装和显示仍需实际设备确认。当前 EXE / APK 仍没有 OTA 功能，需手动下载安装。
